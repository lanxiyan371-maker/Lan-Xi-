# 苍穹战机 · 同关竞技电脑试玩版

在 V2 像素末世版上新增的电脑试玩功能。当前使用本地规则 AI，尚未连接 AI Pyramid 或运行 NPU 推理。

## 打开游戏

本机入口：<http://127.0.0.1:8853/#race>。工作区可双击“一键启动同关竞技.cmd”恢复服务并打开游戏。

分发 ZIP 解压后打开 `race.html`，或打开 `index.html` 后点击右上角“玩家 vs AI · 同关竞技”。必须保留同级 `art-v2` 图片目录。浏览器阻止本地资源时，在解压目录运行 `python -m http.server 8853 --bind 127.0.0.1` 后访问上述入口。

## 玩法

- 点击“开始比赛”，玩家手动驾驶，AI 自动驾驶，双方独立战场同步开始。
- 方向键 / WASD 移动，自动射击，C 技能，X/B 炸弹，Esc/P 暂停双方。手机上按住玩家战场拖动，移动仍受飞机速度限制；底部有技能和炸弹按钮。
- 最多 180 秒。得分优先，同分比较生存时间，仍相同则平局。一方阵亡后成绩冻结，对手继续；双方阵亡提前结算。
- 双方默认猎鹰、标准机炮、普通难度、相同初始生命与技能冷却，各有 3 枚手动炸弹。炸弹补给立即清屏，不扣手动炸弹。普通模式保留原操作。
- 桌面并排查看两个战场；窄屏使用“玩家 / AI”按钮切换。切换场景不会暂停；切出浏览器或窗口失去焦点会同步暂停，回来后点击继续。
- 同种子重赛保留本局种子，新关卡产生新种子；准备页可手动填写 0 到 4294967295 的整数。
- 勾选“双方自动驾驶演示”可以看两架自机自动闯关，演示结果单独标注，不作为玩家手动比赛成绩。
- 最近 20 局竞技记录使用独立浏览器存储，不增加普通金币、成就、累计击杀或普通排行榜。存储被禁用时，本局结算仍可查看。

## 公平性与当前边界

开赛前生成固定的三分钟遭遇表，四个区域各 45 秒，每区有普通敌机和一个 Boss。敌机类型、出生时间、初始参数由种子确定；补给与分裂子机使用稳定敌机编号派生随机数，障碍物按统一时钟和独立种子生成。清怪速度、掉落与视觉特效不会改变后续敌机序列。

区域切换在双方同一时刻清除上一场景残留的敌机、弹丸与补给。竞技取消 Boss 击杀慢动作对物理的影响，保证推进速度一致。玩家位置不同会改变瞄准弹轨迹与拾取结果；敌机存活时间不同也会影响射击次数。

本地 AI 根据可见敌机、当前弹丸速度、障碍物与补给选择普通方向输入；共享移动速度、技能冷却和炸弹限制，不读取未来遭遇表，没有额外生命或无敌。面板耗时是本地决策耗时，不是 NPU 耗时。

本版不含可用的 Pyramid 推理连接。设备到位后增加桥接服务、模型决策、超时与旧答案过滤，并实测端到端延迟。已有 `source: local-rules` 决策格式可用于区分未来的模型来源。

V1、V2 已交付包保留，V2 源码快照位于工作区 `backups/V2`。上游代码许可证见 `LICENSE`，用户素材来源见 `art-v2/sources.json`。

# 返回首页

普通游戏和同关竞技右上角都有“返回首页”。点击会结束当前对局并回到普通游戏首页，已有存档和已结算竞技记录保留。重新开始、同种子重赛仍直接开局。
