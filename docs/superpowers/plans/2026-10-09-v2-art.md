# V2 像素末世素材接入计划

**目标：** 将用户生成素材接入现有中文游戏，提供浏览器试玩版。

**设计：** 使用原始 PNG 与精灵区域清单，运行时建立小尺寸 Canvas 缓存；只修改绘制层。3 架自机、9 种敌机、4 个 Boss、弹药和 6 种补给各自映射资源。组合图按网格和 Alpha 边界识别区域，动画使用共同边界保持尺寸变化。素材加载失败时沿用原绘制。背景采用缓慢往返平移，避免将未经无缝处理的图片强行循环。

**技术：** TypeScript / Canvas / Vite / Vitest。
