# 苍穹战机 V2 · 像素末世行动

用户提供的 39 张素材已保存在工作区 `assets-v2-review`，本版选用其中 26 张原图，建立 77 个精灵/动画区域。原 PNG 未重写；原包及 SHA256 清单均已保留。

## 试玩

本机服务：<http://127.0.0.1:8853/>。

分发包解压后打开 `index.html`，必须保留同级 `art-v2` 文件夹。也可以在解压目录运行 `python -m http.server 8853` 后访问上述地址。V2 的图片是独立资源，不再只有一个 HTML 文件。

方向键移动，空格射击，F 切换自动射击，X/B 炸弹，C 技能，Esc 暂停。菜单的上下键切换模式，左右键切换战机，方括号切换武器。练习模式可用 `-` / `=` 设置起始波次，5、10、15、20 波可查看四个 Boss。练习模式默认无敌，不计奖励。

## 已接入

- 三架自机：猎鹰、幻影、堡垒；尾焰动画与旋转倾斜。
- 九种普通/特殊敌机，四个 Boss；保留治疗范围、狙击瞄准等战斗提示。
- 标准机炮、穿甲弹、散弹、追踪导弹与敌方弹丸；散弹从组合图中取单颗弹丸。
- 六种补给箱，武器补给显示对应图标。
- 四张关卡背景、金属残骸、炮台与传送装置。
- 六帧爆炸与四帧尾焰，菜单展示所选飞机。

素材系统只改绘制层，命中判定、敌机行为、关卡推进和存档沿用原游戏。大图解码后建立小尺寸精灵缓存并释放源图引用，绘制时不反复裁切原始大图。资源不可用时回退到原绘制。

## 当前边界

- 左右倾斜候选图的造型不完全一致，暂不直接作为逐帧姿态；使用基础飞机旋转。
- 四张背景未确认为无缝图，采用缓慢往返平移。
- 激光仍采用原有连续光束，以匹配原判定长度。独立激光素材已定义区域，尚未替换连续光束。
- 命中火花、枪口闪光、拾取与护盾帧图已定义区域；当前仍沿用原粒子/护盾表现，尚未逐项替换。
- 当前已验证浏览器版本；尚未在 AI Pyramid 上验证资源加载、帧率和输入。
